## 🚀 How to Run

1. Install Java JDK.
2. Clone this repository:
   ```bash
   git clone https://github.com/vanshikavs-tech/Java-Problem-Solving.git
   ```
3. Compile a program:
   ```bash
   javac FileName.java
   ```
4. Run it:
   ```bash
   java FileName
   ```
